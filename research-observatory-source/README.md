# Research Observatory

Private research companion to the existing APEX-G Research Atlas GitHub Pages site. Neither APEX-G nor either RasaChatbot repository is replaced.

## Included

- Retains the source-controlled Research Atlas registry, per-paper review links, evidence explorer, synthesis, acquisition queues, repository timeline and clinical evaluation UI.
- Bundled snapshot: 2026-11-09 08:39 UTC; 137 canonical records, 92 archived PDFs, 10 read-complete and 82 visual-verification pending, as reported by APEX-G. This is not a fresh scientific audit.
- Per-paper evidence/Markdown drafts and synthesis notebook; explicit private SQL saves, per-user authorization, optimistic revision checks and JSON/Markdown exports.
- JSON/JSONL clinical run imports, turn/state/provenance/claim audits, observed latency/tokens/cost, variant groups, matched scenario coverage, ablation and stress labels.
- Existing Python orchestration, SQL/FTS retrieval, SSE streaming and clinical UI remain external and unchanged.

## Boundaries

GitHub connector eligibility was unknown during creation. Live refresh and direct main-branch writes are unavailable, explicitly marked in the UI. Reload snapshot reads the bundled JSON; it does not query GitHub. Export Markdown drafts and integrate them through the existing repository workflow. There are no generated evaluation results, model scores, DOI values or scientific claims.

Clinical imports replace the currently loaded run set. They remain in browser memory until Save workspace is clicked. Save stores the current runs and personal drafts in D1 under the authenticated visitor ID. Clearing imported runs affects the current session; click Save to persist the cleared state. Export before reloading unsaved edits. Concurrent saves are rejected rather than overwriting a newer revision.

## Source provenance

Retained frontend and compiler originated from `Armanasq/APEX-G/research-workspace` on main. The repository's own snapshot records detailed provenance, canonical paper links and source revisions. `retained/` preserves the original implementation; `public/atlas/` contains the adapted UI. Full-text PDFs remain in the original project. No private provider tokens are embedded.

## Run

Node 22.13 or newer. `npm ci`, `npm run db:generate` for new schema changes only, `npm run dev`, and `npm run build`. Sites deploys D1 migrations. API requests require platform-provided authenticated identity. Unauthenticated preview can exercise the research UI but cannot save records. No substitute identity headers are generated by the client.

## Compatibility

`public/atlas/EVALUATION_SCHEMA.md` describes actual run export fields. The optional `scripts/export_evaluations.py` accepts existing JSON/JSONL records, validates identifiers and metrics, and exports JSON without inferring missing values. Use at the evaluator/export boundary after de-identification. It does not call models, alter routing, or replace SSE.

## Verification

Frontend syntax, source snapshot shape/counts, production build and browser navigation are checked. Hosted saves require signed-in identity and must be verified separately from publication. GitHub writes remain unavailable.
